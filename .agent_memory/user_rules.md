# Предпочтения и правила пользователя

## 2026-09-21 — Начальные правила
- Контент сайта должен оставаться на русском языке.
- Сохранять существующий визуальный стиль; не делать редизайн без отдельного запроса.
- Не удалять контент, разделы, социальные ссылки, Telegram, WhatsApp и функциональность.
- Выполнять точечные правки в указанном пользователем блоке; остальное оставлять как есть.
- Сохранять ровно один H1 и логическую структуру H2/H3, семантическую HTML-разметку.
- Не вводить React, Vue, крупные библиотеки и лишний JavaScript.
- Использовать существующие реальные сведения о кондитерской, не выдумывать бизнес-факты.
- FSDB: читать релевантную память перед каждым ответом; до финального ответа добавлять новые значимые факты и проверять выполнение обновления.
- Не перезаписывать файлы памяти целиком при обычном обновлении; при превышении 100 строк сжимать старые записи.
- Фразы «ты забыл контекст», «проверь базу», «обнови память» требуют немедленного чтения .agent_memory/.
- Корневой AGENTS.md должен содержать: Always use FSDB Protocol in ./.agent_memory/ before answering
