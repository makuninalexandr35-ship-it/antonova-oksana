# Решения

## 2026-09-21 — Зафиксированные решения
- Сохранена лёгкая архитектура HTML/CSS/JS; React, Vue и крупные библиотеки не нужны.
- Основной SEO-адрес https://antonovaoksana.ru/ выбран пользователем; HTTPS он планировал настроить.
- Использована Organization: достоверный полный адрес для Bakery/LocalBusiness не предоставлен.
- Не добавлять вымышленные адрес, часы работы, отзывы, рейтинги и другие сведения о бизнесе.
- Оригиналы фотографий сохранены; для загрузки созданы WebP-варианты, логотипы с lossless-сжатием.
- Canonical/sitemap содержат одну главную страницу; якоря не являются отдельными страницами.
- robots.txt действует только из корня hostname; /antonova-oksana/robots.txt не управляет github.io.
- Мобильное фото с лебедями получило естественную высоту, чтобы сохранить весь кадр без обрезки.
- FSDB хранится в .agent_memory/; обычные обновления только добавляют записи, сжатие старых записей — при превышении 100 строк.
