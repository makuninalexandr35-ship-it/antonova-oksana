# Oksana Antonova — Art of Desserts

Codex-ready starter project for a one-page confectionery website.

## Goal
Create a conversion-focused landing page for a Moscow home confectionery that accepts custom dessert orders.

## Primary CTA
Open Telegram and start an order conversation.

Telegram contact:
- Username: `@antonovaov`
- Phone: `+7 964 728-18-44`

## Business facts
- Location: Moscow
- Cakes: 3000 ₽ / kg
- Decoration: calculated separately
- Recommended portion: 150–200 g per guest
- Best lead time: 2 weeks
- Minimum recommended lead time: 1 week
- Rush order: 2–3 days, +20% if capacity allows
- Delivery: pickup or courier, delivery calculated separately
- Experience: 3 years
- No reviews block for now
- Brand should be product-led, not personality-led

## Visual direction
Use the approved Version 1 concept:
- Deep burgundy
- Warm cream
- Champagne / restrained gold accents
- Editorial serif headlines
- Clean sans-serif UI text
- Large product photography
- No heavy shadows
- Premium but warm, handcrafted tone

## Important UX rules
- No long form.
- Telegram is the main conversion path.
- Keep CTA visible and repeated through the page.
- On mobile, use a sticky “Заказать” / “Telegram” action.
- Use real photography only.
- Do not invent testimonials, awards or order counters.
- Other product prices will be added later.
